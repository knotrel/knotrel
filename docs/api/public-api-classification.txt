# Stability classification of every named public Rust item.
#
# Format: one line per public item, "<class> <key>", class = stable |
# experimental | internal (docs/compatibility.md, section 2). The key is the
# item's public path in docs/api/public-api-knotrel-core.txt or
# public-api-knotrel-server.txt, or "impl <Trait> for <Type>" for a trait
# implementation (listed after its type's members).
#
# Checked in CI by scripts/public-api.py (job "public API"):
# - every public item and trait implementation has exactly one line here, and
#   every line names one: a new item or implementation fails CI until it is
#   classified here;
# - a member or implementation never has a higher class than its parent
#   (stable > experimental > internal); items behind the test-support feature
#   are internal; implementations of unstable traits (Freeze, UnsafeUnpin,
#   StructuralPartialEq, TrivialClone) are internal;
# - a stable key may become experimental, internal or disappear only with an
#   approved [[narrowing]] in docs/api/public-api-policy.toml (compared with
#   the pull request's base);
# - docs/stability.md agrees: it lists every crate-root item and every member
#   whose class differs from its parent's, with the same class.
# Keep the file in this order: by path within each crate, implementations
# after their type's members.
