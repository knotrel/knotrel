# Stability classification of every named public Rust item.
#
# Format: one item per line, "<class> <path>", class = stable | experimental |
# internal (docs/compatibility.md, section 2). Paths are the public paths of
# docs/api/public-api-knotrel-core.txt and public-api-knotrel-server.txt.
#
# Checked in CI by scripts/public-api.py (job "public API"):
# - every named public item has exactly one line here, and every line names a
#   public item: a new public item fails CI until it is classified here;
# - a member never has a higher class than its parent (stable > experimental
#   > internal); items behind the test-support feature are internal;
# - docs/stability.md agrees: it lists every crate-root item and every member
#   whose class differs from its parent's, with the same class.
# Trait implementations are not named items: they share the class of the
# implementing type. Keep the file sorted by path within each crate.
