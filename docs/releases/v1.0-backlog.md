# v1.0 backlog: non-blocking findings and suggestions

**Source:** the [R3e independent AI review](v1.0-ai-review.md) (sections 4 and 5),
reviewed at `e1be11c`, blocking findings resolved at `1dd97b8`. Created
2026-11-23 at the maintainer's request: "record the non-blocking findings and

incompatible changes after 1.0. Not all need to be implemented before the RC."

Every item keeps its review ID; the review row has the evidence and the
proposed resolution. When an item is resolved, its **Status** here and its
**Resolution** in the review record the PR and merge SHA.

## How to read it

- **Incompatible after 1.0?**
  - **Yes:** the natural fix changes a stable behavior, code or meaning, so
    after the freeze it needs a major release or an approved exception
    ([compatibility.md](../compatibility.md) §3). Decide before the freeze:
    fix it now, or freeze the current behavior and document it.
  - **Maybe:** a compatible fix exists (usually documenting what the code
    does); only the other option would be incompatible.
  - **No:** documentation, tests, tooling or additive changes.
- **Target:** *decide before freeze* (Yes items), *before rc* (other gates
  rely on it), or *1.x* (any later minor release).
