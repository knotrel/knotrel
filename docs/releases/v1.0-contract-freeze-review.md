# v1.0 contract freeze review (readiness criterion 1, rc gate R3d)

**Status: proposed, 2026-11-22. Nothing here is decided.** The freeze is the
maintainer's decision ([rc plan](v1.0.0-rc-plan.md), R3d: "Approve the frozen
list"). This review prepares it; the independent AI review of the whole 1.0
contract set (criterion 9, R3e) comes after and is done separately.

Written on branch `docs/contract-freeze-review`, cut from `main` at `e118711`
(after the threat model #106, the soak #105, the D1 fix #104 and the
reproducible-build check #107/#109). Policy and classes:
[compatibility.md](../compatibility.md); current classification:
[stability.md](../stability.md) (approved 2026-11-21).

## 3. Findings

Severity:
- **Freeze**: a shape that 1.0 makes permanent; decide before approving the
  frozen list.
- **rc**: documentation or classification error to fix before the rc tag;
  no behavior change, or an additive one.
- **Minor**: drift to fix when convenient.

Every resolution is a **proposal**. None is applied on this branch.

### 3.1 Rust

| ID | Severity | Finding | Proposed resolution |
| --- | --- | --- | --- |
| R1 | Freeze | `EngineConfig` is an **exhaustive** stable enum that carries two **experimental** variants (`EulerTour`, `Hdt`). Removing an experimental engine, or adding any new engine, is a breaking Rust change that `cargo-semver-checks` fails, which contradicts "experimental may be removed in any minor release" and blocks new engines until 2.0. | Add `#[non_exhaustive]` to `EngineConfig` before the rc. This breaks downstream exhaustive `match`es, so it needs a maintainer-approved exception: no deprecation path exists for `#[non_exhaustive]`; declare it in the core's `cargo-semver-checks` configuration and the release notes. Alternative: freeze as is and accept that a new engine requires 2.0. |
| R2 | Freeze | Other stable enums are exhaustive: `GraphError`, `IncidenceError` (core); `ServerMode`, `Phase`, `ShutdownOutcome` (server, incl. the struct variant `DeadlineExceeded { abandoned }`). After 1.0, a new error or phase requires 2.0. `LifecycleError` and `LifecycleStorage` are already `#[non_exhaustive]` (precedent). | Same decision as R1, per enum. Recommendation: `#[non_exhaustive]` on `GraphError`, `IncidenceError` and `Phase`, where new cases are plausible; freeze `ServerMode` and `ShutdownOutcome` as they are. |
| R3 | Freeze | Stable structs with only public fields and no `#[non_exhaustive]`: `GraphLimits`, `NodeSpec`, `EdgeSpec` (inputs, built with struct literals) and `EdgeState` (output only). Adding a field after 1.0 is breaking. | Freeze `GraphLimits`, `NodeSpec` and `EdgeSpec` as they are; `#[non_exhaustive]` on `EdgeState` (same exception as R1). The experimental counter structs (`ForestStats`, `HdtStats`, `HdtLevelStorage`, `HdtStorageStats`) may change in a minor release anyway. |
| R4 | rc | `router_with_lifecycle` is classified **Internal**, but it is the only way to connect a stable `Lifecycle` to a router served by the stable `serve`. The binary uses it (`main.rs:32`), the crate docs recommend it (`lib.rs:16`, `lib.rs:136`), and so does `http-api.md` (line 414). `router_with_config` creates its own ready lifecycle, so `/ready` would not follow the drain. | Reclassify `router_with_lifecycle` as **Stable**. Keep the two `router_with_seeded_*` helpers Internal; they exist only with `test-support`. |

| R7 | rc | stability.md names `EngineConfig::Ett`, which does not exist: the variant is `EngineConfig::EulerTour`; `ett` is its `as_str` value, used by the variable and the HTTP field. | Correct the name; classification unchanged. |
| R8 | Minor | stability.md lists "limits" under `Graph`, which has no limit accessor (limits live on `ConnectivityGraph` and `LifecycleGraph`). `EngineConfig::as_str` and `ConnectivityGraph::{new, with_limits, limits, engine}` are not named. | R9 | Minor | `ReferenceGraph` is Internal, but its rustdoc does not say so; docs.rs presents it like the other graphs. | Add a sentence to its rustdoc: "Internal test oracle; no stability promise." Optionally `#[doc(hidden)]`. |
