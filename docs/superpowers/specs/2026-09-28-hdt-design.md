# Experimental HDT connectivity

Goal: reduce repeated replacement-edge work after tree deletions while preserving growing arbitrary u64 IDs, exact answers, shared synchronous queries, and the existing compact default. Compare with the current ETT and adopted petgraph baseline; do not assume an asymptotic improvement wins practical latency or memory.

Implement the deterministic level algorithm from Holm, de Lichtenberg and Thorup (JACM 2001), sections 3.1–3.2: https://www.cs.princeton.edu/courses/archive/fall07/cos521/handouts/poly.pdf . Each edge has one level. F_i contains tree edges at levels >= i; each component size is at most U/2^i. Exact-level tree and non-tree incidences have separate subtree aggregates. Insert at level zero. Delete a tree edge from every forest containing it, search downward, promote all exact-level tree edges in the smaller component, then promote internal non-tree edges or select a crossing replacement. A replacement is linked into every forest through its level.

U is the smallest power of two at least V (one for an empty graph). When the vertex universe crosses a power of two, append an empty highest forest containing all current vertices; lower forests and edge levels are unchanged because all size bounds relax. Add each new vertex to existing levels. This incurs O(log V) amortized vertex initialization across a growing history, with linear allocation/level-initialization spikes; no constant worst-case growth promise. With N the largest vertex count in the history, edge updates follow the O(log² N) amortized charging argument and queries use O(log V) AVL roots. Space is O(E + V log V), larger than the one-forest prototype. A single cut can still be expensive.

Use a dedicated marked ETT module derived from our existing AVL implementation, leaving ForestGraph implementation and benchmark identity untouched. This isolates two-bit incidence aggregates from the measured baseline at the cost of duplicated sequence code, to be consolidated only after measurements. Each marked lookup returns one vertex in O(log V), without copying whole smaller components. All exact-level incidences and edge records must agree; only tree edges have per-level arc handles.

Expose HdtGraph and HdtStats (tree_cuts, candidate_edges, replacements, tree_promotions, non_tree_promotions, levels_visited). Keep diagnostics separate from ForestStats. After differential and invariant checks, add experimental EngineConfig::Hdt and KNOTREL_ENGINE=hdt; compact remains default. No runtime migration or caching.

Benchmark selector hdt, identity knotrel-core/hdt-levels-v1; keep historical selectors/identities. Add dense-bridge-churn-v1 and redundant-bridge-churn-v1, independently answered by clique membership and active bridges. Measure setup, complete operation time, update tails, queries, warmups/repeated-query controls and whole-process peak RSS. These workloads are deliberate stress cases, not market evidence. Begin at bounded sizes because dense graphs have quadratic edges and HDT has per-level storage.
