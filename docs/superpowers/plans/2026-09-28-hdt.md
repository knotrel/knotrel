## Execution notes

- Initial HDT implementation and invariant/semantic tests passed independent algorithm review; adapters/workloads separately reviewed.
- Initial collections: 128 dense, 64 sparse and 32 repeated-query processes (v1). Dense repeated repairs improved, but pure sparse paths exposed unnecessary tree promotions and memory growth.
- Added candidate-free smaller-side shortcut after an independent correctness/amortization review. Regression first failed with 511 promotions instead of zero. Extended tests retain multi-level coverage using clique blocks and verify lower-level replacement after an empty higher level.
- Versioned optimized benchmark identity as hdt-levels-v2; v1 raw reports preserved. Final comparisons include dense, sparse, longer and repeated-query runs.
- Collector fix: source patches now exclude results/ even when prior reports are staged. A temporary-repository test reproduces the oversized-snapshot cause. The first dense collection completed before termination could occur; its patch was narrowed with original/replacement hashes and byte counts recorded in manifest postprocessing. Timings and traces unchanged.
